# Global Coding Standards (Mandatory)
1. DRY (Don't Repeat Yourself): Extract duplicate logic into reusable functions.
2. Error Handling: All async/network calls must have try/catch blocks.
3. Naming & Language: **All code must be written in English by default** — including variable names, function names, class names, comments, documentation, and commit messages, regardless of the user's conversational language.
4. Comments: Code must be self-documenting. Only comment on complex business logic.
