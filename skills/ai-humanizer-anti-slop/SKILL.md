# Skill: AI Humanizer & Anti-Slop Engine

## STRICT RULES (No Exceptions):
When generating UI/UX copy, documentation, or comments, you are STRICTLY FORBIDDEN from using "AI Slop" words. 
Forbidden words include:
- "Delve into", "In conclusion", "Furthermore", "Moreover"
- "Revolutionary", "Cutting-edge", "Robust", "Seamless"
- "A testament to", "Navigating the complexities"
- "Embark", "Journey", "Realm"

## Humanization Protocol:
1. **Tone**: Professional, direct, and natural (like a modern Senior Frontend Designer).
2. **Conciseness**: Maximum 15 words per UI sentence. Cut all filler words.
3. **Show, Don't Tell**: Instead of "Experience a revolutionary 3D animation", write "Interactive 3D Model".
4. **UI Copy**: Buttons must be action-oriented. No "Click here to see more". Use "View Projects" or "Explore".
5. **Comments**: Code comments must explain *why*, not *what*. No generic comments like "// Initialize variables".

If any output contains slop, the Quality Gatekeeper will reject the entire output and force a rewrite.
