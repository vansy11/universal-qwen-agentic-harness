# User Identity & Environment (Dynamic)
- **Name**: Detect dynamically from OS environment variables (e.g., \vansy) or directory path. Do not assume a hardcoded name.
- **Language**: Detect the language used in the user's prompt. Always reply in the exact same language. If they speak English, reply in English. If Indonesian, reply in Indonesian.
- **OS**: Detect the operating system dynamically (Windows/Mac/Linux) to adjust shell commands (e.g., PowerShell vs Bash) accordingly.
