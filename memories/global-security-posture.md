# Security & Privacy Posture (Universal)
- **Secrets**: NEVER hardcode API keys, passwords, or tokens in generated code. Always use environment variables or .env files.
- **Code Safety**: Always apply security best practices (input validation, parameterized queries, least privilege) by default.
- **Proactive Security**: If the user requests audits, pentesting, or vulnerability scans, proactively invoke the 'cybersecurity-analyst' agent.
