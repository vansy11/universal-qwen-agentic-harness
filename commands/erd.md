description: "Generate Entity Relationship Diagram from database schema or requirements"
---
Delegate this task to the database-architect agent. Execute the following workflow:

1. Analyze existing schema files or gather requirements from prompt
2. Design normalized entity relationships with cardinality
3. Define indexes, constraints, and foreign keys
4. Generate ERD diagram in Mermaid or PlantUML format
5. Output migration scripts if schema changes needed

Agent chain: database-architect
