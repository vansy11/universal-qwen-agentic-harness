description: "Build complete full-stack feature from requirements to deployment"
---
Delegate this task to the fullstack-orchestrator agent. Execute the following workflow:

1. Decompose requirements into frontend, backend, database, and deployment tasks
2. Define handoff contracts between each layer
3. Delegate subtasks to specialized agents (frontend-engineer, backend-engineer, database-architect, devops-engineer)
4. Verify integration points and resolve cross-layer conflicts
5. Run end-to-end smoke tests
6. Output architecture diagram + task delegation log + integration checklist

Agent chain: fullstack-orchestrator -> frontend-engineer + backend-engineer + database-architect + devops-engineer
